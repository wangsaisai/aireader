# AIReader Android App

This is the Android version of the AIReader application, built with Kotlin and Jetpack Compose.

## Features

-   **Unified Chat Interface**: Combines book search and AI Q&A in a single view.
-   **Modern Tech Stack**: Built with Kotlin, Jetpack Compose, Coroutines, and Flow.
-   **MVVM Architecture**: Follows the recommended Android app architecture for maintainability and scalability.
-   **Multi-language Support**: Supports English, Simplified Chinese, and Traditional Chinese.

## Development Setup

1.  **Open in Android Studio**: Open the `android` directory in Android Studio.
2.  **Sync Gradle**: Let Android Studio sync the Gradle files and download the required dependencies.
3.  **Run the App**: Build and run the app on an emulator or a physical device.

Note: The app is configured to connect to a local backend server at `http://10.0.2.2:8000`, which is the standard address for accessing the host machine's localhost from the Android emulator.
